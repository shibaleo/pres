## 記法と部品の一覧

<div style={{ fontSize: '0.52em' }}>

| 書き方 | 用途 |
|---|---|
| `---` / `--`（行単独） | 横のスライド／縦のスライド（上の続き）に区切る |
| `\begin{theorem}` … / `<Theorem>` | 定理環境（lemma / proposition / corollary / definition / proof） |
| `\label` `\ref` `\eqref` `\begin{equation}` | 相互参照と番号付きの式 |
| `\pause` `\only<2>{…}` `\uncover<2->{…}` / `<Fragment>` | 段階表示（Beamer 記法と reveal の両方） |
| `\input{file}`（行単独） | 別のファイルを取り込む（番号・参照は通しのまま） |
| `\cite{key}` / `<Bibliography />` | 文献の引用と、文献リスト |
| `<Notes>` | 発表者ビュー（`S` キー）だけに出るメモ |
| `<Frame>` `<Cols>` `<Col>` `<Center>` `<Byline>` `<Note>` `<Code>` | 色付きの枠／段組み／中央寄せ／発表者欄／囲み／コード |

JSX 部品の一覧は `src/deck/mdx-components.tsx`。個別の図（Globe など）は原稿の先頭で import する。

</div>

## 定理環境と相互参照

<Cols style={{ fontSize: '0.56em' }}>
<Col>

**書き方**（LaTeX と同じ）

<Code>{`\\begin{definition}[凸関数]\\label{def:convex}
任意の $t \\in [0,1]$ で
$f(tx+(1-t)y) \\le tf(x)+(1-t)f(y)$
\\end{definition}

\\begin{theorem}[Jensen]\\label{thm:jensen}
定義 \\ref{def:convex} の $f$ について

f(\\mathbb{E}X) \\le \\mathbb{E}f(X)
\\end{equation}
\\end{theorem}

\\begin{proof}

\\end{proof}`}</Code>

</Col>
<Col>

**表示**

\begin{definition}[凸関数]\label{def:convex}
任意の $t \in [0,1]$ で
$f(tx+(1-t)y) \le tf(x)+(1-t)f(y)$
\end{definition}

\begin{theorem}[Jensen]\label{thm:jensen}
定義 \ref{def:convex} の $f$ について
\begin{equation}\label{eq:jensen}
f(\mathbb{E}X) \le \mathbb{E}f(X)
\end{equation}
\end{theorem}

\begin{proof}
式 \eqref{eq:jensen} は有限和の場合から極限で従う。
\end{proof}

</Col>
</Cols>

<Notes>

環境は theorem / lemma / proposition / corollary / definition / proof。定理の番号はビルド時にデッキ全体で振られ、式の番号は MathJax が振る（別々の通し番号）。JSX の `<Theorem id="…">` でも書ける。

</Notes>

## 複数行の式（align）

<Cols style={{ fontSize: '0.56em' }}>
<Col>

**書き方**

<Code>{`\\begin{align}
(a+b)^2 &= a^2 + 2ab + b^2 \\label{eq:sq} \\\\
        &= (a-b)^2 + 4ab \\nonumber \\\\
f(x) &= \\begin{cases} 1 & x > 0 \\\\ 0 & x \\le 0 \\end{cases}
        \\label{eq:f}
\\end{align}

式 \\eqref{eq:sq}、\\eqref{eq:f} と
前のスライドの \\eqref{eq:jensen}`}</Code>

</Col>
<Col>

**表示**

\begin{align}
(a+b)^2 &= a^2 + 2ab + b^2 \label{eq:sq} \\
        &= (a-b)^2 + 4ab \nonumber \\
f(x) &= \begin{cases} 1 & x > 0 \\ 0 & x \le 0 \end{cases}
        \label{eq:f}
\end{align}

式 \eqref{eq:sq}、\eqref{eq:f} と
前のスライドの \eqref{eq:jensen}

</Col>
</Cols>

<Notes>

行ごとに番号が付き、\nonumber / \notag / \tag の行は自動番号なし。番号付けと参照の解決は MathJax（AMS と同じ規則）。後ろにある式への参照は表示できない（警告になる）。

</Notes>

## 段階表示（Beamer の overlay）

<Cols style={{ fontSize: '0.56em' }}>
<Col>

**書き方**

<Code>{`最初から見える

\\pause

次のステップで現れる

- \\uncover<+->{箇条書きを}
- \\uncover<+->{一つずつ}

\\only<4>{4 枚目だけ（場所も消える）}

\\uncover<4->{4 枚目から（場所は残る）}

<Fragment>

</Fragment>`}</Code>

</Col>
<Col>

**表示**

最初から見える

\pause

次のステップで現れる

- \uncover<+->{箇条書きを}
- \uncover<+->{一つずつ}

\only<4>{4 枚目だけ（場所も消える）}

\uncover<4->{4 枚目から（場所は残る）}

<Fragment>

reveal の Fragment も使える

</Fragment>

</Col>
</Cols>

<Notes>

overlay の指定: `<2->` 2 枚目から、`<2>` 2 枚目だけ、`<2-3>` 範囲、`<-3>` 3 枚目まで、`<+->` 次のステップから。環境にも付けられる: `\begin{theorem}<2->`。

</Notes>
